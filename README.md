# Personal Mini-Toolkit - Week 8 Final Project

## What My Toolkit Does
My Personal Mini-Toolkit is a menu-driven program with 4 tools:
1. **To-Do List** - Add, view, and remove tasks using a list
2. **Simple Calculator** - Add, subtract, multiply, and divide two numbers
3. **Number Guessing Game** - Guess a random number between 1 and 20
4. **Name Formatter** - Shows your name in uppercase, lowercase, and title case
